# Socialfy
- Discord RPC integration on Minecraft

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/W7W312TUST)

This mod is focused on minimalized Discord Rich Presence (RPC), which probably some of you love this style... me either lol. *and it's configurable*
> This is my first Minecraft mod, I learned Java just for this lmao

## Compatibility

| Minecraft | Java | Notes |
|-----------|------|-------|
| 26.1 through 26.x | 25 | Single-jar target; verified against 26.3. Earlier 26.x releases still need validation. Unobfuscated, so no mappings are used. |
| 1.21.10   | 21   | Original release (see earlier tags/commits). |

Requires Fabric Loader and Fabric API. YetAnotherConfigLib (YACL) is optional and enables the configuration screen; Mod Menu is optional.
